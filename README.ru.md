# LumiBot AI Trading

[English](README.md) · [中文](README.zh-CN.md) · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Português](README.pt.md) · **Русский**

**Создавайте торговых ИИ-агентов, проверяйте их на истории и торгуйте той же стратегией.**

LumiBot: бесплатный Python-фреймворк с открытым исходным кодом для торговых ботов. Пишите правила на Python, поручайте решения ИИ-агентам или сочетайте оба подхода. Проверяйте стратегию на исторических данных, изучайте решения и сделки, затем подключайте брокера для симуляции или реальной торговли.

Это краткое изложение английского README и главной страницы документации. Полный код находится в [английском README](README.md) и [документации](https://lumibot.lumiwealth.com/).

## Почему LumiBot

- **Встроенные торговые ИИ-агенты:** исследуют данные, рассуждают и выставляют заявки по вашим инструкциям.
- **Сначала бэктест, затем торговля:** проверяйте решения ИИ и правила Python на истории с графиками, сделками и журналами.
- **Одна стратегия для бэктеста и торговли:** сохраняйте класс стратегии, меняя источник данных и конфигурацию запуска с брокером.
- **Разные классы активов:** акции, опционы, фьючерсы, валюты, криптовалюты и рынки прогнозов в зависимости от [поддерживаемого брокера](https://lumibot.lumiwealth.com/brokers.all.html).
- **Решение доходит до брокера.** Просматривайте заявки, исполнения и записи решений. [Как устроено исполнение](https://lumibot.lumiwealth.com/execution_gap.html).

## Начало работы

Нужен Python 3.10 или новее. Запустите пример бэктеста на бесплатных дневных данных:

```bash
pip install lumibot
lumibot demo
```

Для ИИ-примеров нужны учётные данные модели; вызовы могут быть платными. Для симуляции или реальной торговли нужны счёт и учётные данные брокера. См. [ИИ-пример](README.md#run-your-first-ai-backtest), [настройку CLI](https://lumibot.lumiwealth.com/cli.html) и [режимы запуска](https://lumibot.lumiwealth.com/strategy_run_modes.html). Бэктест не гарантирует будущие результаты.

## Дайте агентам суперсилы — бесплатно

Подключите BotSpot MCP к стратегии LumiBot: экономические данные, новости, документы SEC, стратегии Marketplace и знания сообщества.

![Дайте агентам суперсилы — бесплатно](docs/assets/readme/botspot_mcp_superpowers.png)

Ваш помощник уже подключён к BotSpot? Скажите: «Подключи этот проект LumiBot к BotSpot MCP». Он может создать API-ключ и сохранить настройки за вас.

**[Подключить агентов](https://lumibot.lumiwealth.com/botspot_mcp.html)**

Выполните эту команду в папке стратегии, войдите в аккаунт и подтвердите подключение, затем снова запустите стратегию. Настройки сохраняются в файле `.env` проекта, а LumiBot автоматически добавляет исследовательские инструменты при создании агента. Укажите в `system_prompt`, что исследовать, и попросите приводить источники, даты и ограничения исторических данных.

```bash
lumibot connect botspot
```

## LumiSafe: режим для начинающих (кратко)

LumiSafe — необязательный режим для начинающих в пакете `lumisafe/`, построенный на LumiBot. Он инвестирует по простому плану из индексных фондов, пропускает каждый ордер через фиксированные правила безопасности (без плеча, коротких продаж и опционов; лимиты на отдельные акции и частоту сделок; пауза на обдумывание при панических продажах и погоне за ростом) и всегда показывает ваш результат рядом с «если бы вы просто держали S&P 500». Торгует **только на учебных (paper) счетах**.

Нужны Python 3.10 или новее и бесплатный **paper**-счёт в Alpaca. Полный список команд (не больше десяти, от клонирования до первой учебной сделки) — в [англоязычном кратком руководстве LumiSafe](README.md#lumisafe-quickstart); дальше достаточно `lumisafe init`, `lumisafe run-paper` и `lumisafe status`. `lumisafe next` показывает, что и когда покупать на собственные деньги; сам он никогда не выставляет заявок.

Учебная программа. Не является финансовой, налоговой или юридической консультацией. Инвестиции могут потерять в стоимости.
